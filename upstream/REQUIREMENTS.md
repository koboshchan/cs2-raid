# Server Requirements

Tested server stack:

- Windows CS2 Dedicated Server, app `730`
- Metamod:Source `2.0.0.1483`
- CounterStrikeSharp `1.0.379`
- .NET `10`

The plugin DLL is already built in `plugin\DeltaOps.dll`.

Official references:

- SteamCMD: <https://developer.valvesoftware.com/wiki/SteamCMD>
- CS2 dedicated servers: <https://developer.valvesoftware.com/wiki/Counter-Strike_2/Dedicated_Servers>
- CounterStrikeSharp: <https://docs.cssharp.dev/>
- Metamod:Source: <https://www.metamodsource.net/downloads.php?branch=master>

The friend must install their own GSLT if the server needs to appear publicly.
Put it in `<ServerRoot>\gslt.txt`; do not send the token in chat.

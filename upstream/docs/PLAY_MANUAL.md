## 2. 按键设置

本机双击 `play-deltaops.bat` 时，脚本会通过 Steam 启动参数自动执行 V/X
绑定，不需要手工操作。

以下步骤用于：

- 外地朋友第一次加入
- 你自己没有用一键脚本，而是直接从 Steam 启动 CS2
- 自动绑定被 Steam 或客户端设置拦截

手动设置每台新电脑只需要做一次。

### 2.1 启用开发者控制台

进入 CS2：

`设置 -> 游戏 -> 启用开发者控制台 -> 是`

按 `Esc` 下面的 `~` 键打开控制台。

### 2.2 绑定 V/X

在 **CS2 游戏控制台** 中逐行执行：

```cfg
bind "v" "css_v"
bind "x" "css_x"
host_writeconfig
```

`host_writeconfig` 会保存按键设置，以后正常启动游戏仍会保留。

注意：

- 这三行输入到 CS2 游戏控制台，不要输入到服务器控制台。
- 不要输入到聊天框。
- 这会覆盖该客户端原来的 V/X 按键绑定。

## 3. 下次开始游戏

服务器和客户端都在同一台 Windows 电脑时：

1. 双击：

```text
C:\cs2server\play-deltaops.bat
```

2. 脚本会先启动带自动 V/X 绑定参数的 CS2 客户端，再启动服务器，等待
   `27015` 可用，最后打开 Steam 连接地址。
3. 如果游戏没有自动进入，双击：

```text
C:\cs2server\join-deltaops.url
```

4. 仍未进入时，打开 CS2 游戏控制台并执行：

```cfg
connect 192.168.1.118:27015
password <REDACTED_SERVER_PASSWORD>
```

服务器已经运行时，重复双击启动脚本不会重复开服。

## 4. 停止服务器

双击：

```text
C:\cs2server\stop-deltaops.bat
```

如果 RCON 停止失败，可以在服务器控制台输入：

```text
quit
```

## 5. 选角色

进入 CT/T 并出生后，中心菜单会显示三名干员：

- `!1`：选择当前页第 1 名
- `!2`：选择当前页第 2 名
- `!3`：选择当前页第 3 名
- `!opnext`：下一页
- `!opprev`：上一页
- 120 秒不选择会自动随机选择

中心菜单每个角色使用单行简表，避免小分辨率下第 3 名角色被底部 HUD 截断；
完整技能说明可随时在聊天框输入 `!roles` 查看。

技能发放的闪光弹、高爆手雷等道具会直接切换到角色手中。CS2 原生高爆手雷
携带上限已由服务器设置为 3 枚。

也可以继续使用聊天命令：

```text
!op 1
!op 2
!op 3
!op 4
!op 5
!op 6
```

暖身阶段可以重选；正式比赛开始后锁定。

## 6. 使用技能

- 按 `V`：技能 1
- 按 `X`：技能 2
- 聊天输入 `!v`：技能 1 的备用方式
- 聊天输入 `!x`：技能 2 的备用方式
- 聊天输入 `!cd`：查看 V/X 剩余冷却
- 聊天输入 `!ops`：查看干员、被动和冷却
- 聊天输入 `!switch`：实时重新打开选角菜单
- 聊天输入 `!switch 1-6`：实时直接切换指定干员
- 聊天输入 `!roles`：查看全部干员

V/X 使用独立冷却：

- 技能成功释放后才开始冷却
- 默认 V 18 秒、X 24 秒
- 死亡、复活、换边和断线重连不会刷新冷却
- 新回合开始时两个技能冷却清零

## 9. 常见问题

### V/X 没反应

在 CS2 游戏控制台重新执行：

```cfg
bind "v" "css_v"
bind "x" "css_x"
host_writeconfig
```

然后重新选择干员并测试。一键启动脚本会在客户端启动阶段自动绑定；从 Steam
菜单普通启动客户端时，CS2 运行中会以 `missing required FCVAR flag` 拒绝
服务器下发的 `bind`，所以需要上面的手动设置。

### 选角菜单没有显示

聊天输入：

```text
!ops
```

如果仍然没有中心菜单，确认服务器已经重启并加载 Delta Ops `1.3.0`：

```text
css_plugins list
```

### 进不去服务器

在本机 PowerShell 执行：

```powershell
netstat -ano -p TCP | Select-String ':27015'
netstat -ano -p UDP | Select-String ':27015'
```

两项都应有监听记录。查看日志：

```text
C:\cs2server\game\csgo\addons\counterstrikesharp\logs\log-all20261101.txt
```

## 10. 外地朋友联机

本机局域网游玩已经可运行。外地朋友加入前还缺两项外部配置：

1. 在路由器把公网 `UDP 27015` 转发到 `192.168.1.118:27015`。
2. 在 `C:\cs2server\gslt.txt` 填入本机申请到的 GSLT，然后重启服务器。

如果宽带没有公网 IPv4，或者路由器显示 WAN IPv4 是
`100.64.0.0/10`、`10.x.x.x`、`172.16.x.x` 至 `172.31.x.x`、
`192.168.x.x`，直接端口映射无法让公网朋友加入。此时应使用有公网入口的
云服务器中转、游戏加速器的联机房间或其他虚拟局域网方案。

不要把 Steam 密码、Steam Guard 验证码或 GSLT 发到聊天中。GSLT 只填在本机文件。

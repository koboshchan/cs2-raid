DeltaOps 1.3.2 provenance

The csproj, two C# files and example config in this directory are byte-for-byte unchanged from DeltaOps-1.3.2-source.zip, SHA256 465fdb7b8d36a03d9d819ab9303ee08e518d66d27c004df78e63c9483d9c8030. Retained code/config hashes are recorded in source.sha256; the original README is retained with an appended note correcting the omitted wrapper instructions. The obsolete build.ps1 wrapper was omitted, as were historical upstream wrappers, by explicit owner request. The archive had six members; this layout intentionally retains five. The original archive contained no license and identified the module author only as "Local server", not a named individual.

The repository-root [LICENSE](../../LICENSE) records that user-provided authorization using the requested copyright holder "DeltaOps contributors" and preserves the named project author credit. This records the owner's authorization, not an independent verification of the friend's copyright ownership. The owner subsequently explicitly authorized MIT licensing of the whole project, including the retained legacy upstream project source. CounterStrikeSharp, Metamod and other third-party dependencies and downloaded assets retain their own licenses; they are not relicensed by the project LICENSE.

The live repository API returned visibility public and private false on November 4, 2026 UTC (November 3 local). Earlier notes calling the repository private were incorrect. No visibility change was made. Source publication was held until the explicit MIT authorization arrived.

The source ZIP and its download link/key are not committed. The root Dockerfile build stages, license, provenance and integration notes are separate from the unchanged upstream files. Build artifacts and downloaded dependencies stay outside git.
